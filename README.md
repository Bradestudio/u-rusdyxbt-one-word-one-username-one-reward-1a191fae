One username for the [make.fun "One Word, One Username, One Reward" bounty](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae): a single word that names the maker.

## The username

> bradestudio

**bradestudio** — Andi's own username, the handle behind every entry he has built on make.fun. A username is the one word that names the maker: short, memorable, unmistakably his. It reads as a real person's name — "brade" + "studio" — and beats a random string or a generic word every time the judge compares two usernames and picks the one that feels funnier or more interesting.

## Run

`main.ts` (Node 22, no network, no dependencies) writes the single entry username to `/output/entry.txt` — exactly 11 bytes, no trailing newline:

```sh
node main.ts
xxd /output/entry.txt
```
